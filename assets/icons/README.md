# Grounded fantasy equipment icons

Each PNG is a transparent-background, 256px-class item icon rendered in a consistent practical-prop, three-quarter presentation. The equipment UI uses `object-fit: contain` and a 30px tool / 32px paper-doll display area, so replacements should preserve transparent padding and a strong central silhouette.

## Current requested assets

- `icon-axe-stone`, `icon-axe-iron`, `icon-axe-steel`
- `icon-knife-stone`, `icon-knife-iron`, `icon-knife-steel`
- `icon-pick-stone`, `icon-pick-iron`, `icon-pick-steel`
- `icon-torch`, `icon-backpack`
- `icon-staff-wood`, `icon-staff-iron`, `icon-staff-steel`
- `icon-robe-apprentice`, `icon-ring-mana`

## Completion pass additions

The equipment registry also has one distinct asset per currently equippable secondary gear item: crude satchel; crude, patched, and repaired packs; linen and leather shirts; wool and leather trousers; foraging basket; plain and reinforced waterskins; crude shoes and travel boots; and one-, two-, and three-vial tonic belts. Crafted mana, warding, greater-mana, and greater-warding rings have separate files as well.

`icon-spare.png` is a transparent fail-safe only; it is never intended as an authored item icon.
